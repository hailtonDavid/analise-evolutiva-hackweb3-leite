# Checklist de submissão final

## Antes do envio

- [ ] Conferir se o repositório GitHub está público.
- [ ] Conferir se o README abre corretamente na página inicial do GitHub.
- [ ] Rodar `python -m pytest -q`.
- [ ] Rodar `cd hardhat && npm install && npm test`.
- [ ] Testar `http://127.0.0.1:5000/simulador`.
- [ ] Testar `http://127.0.0.1:5000/casos-leite`.
- [ ] Testar `http://127.0.0.1:5000/investidor`.
- [ ] Gerar uma evidência e abrir a verificação pública.
- [ ] Atualizar o README com link do vídeo-pitch.
- [ ] Atualizar o README com link da aplicação publicada, se houver.
- [ ] Atualizar o README com endereço do contrato em testnet, se houver.
- [ ] Conferir se `docs/Apresentacao_HackWeb_Analise_Evolutiva.pdf` está no repositório.

## Formulário oficial

Enviar:

1. link do repositório GitHub;
2. link do PDF de slides;
3. link do vídeo-pitch no YouTube como não listado;
4. link da aplicação publicada, se houver;
5. endereço/link do contrato em testnet, se houver.
